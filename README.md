## What it does

`main.py` (pure Python stdlib, deterministic, no network) writes one single-line
joke excuse for a missed deadline to `/output/entry.txt`:

> I missed the deadline because I gave it a head start, and it is now beating me by three days and one very passive-aggressive email.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
